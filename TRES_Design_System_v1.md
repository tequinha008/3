# TRES — Design System v1.0

## Nome visual

TRES  
Sistema interno para solicitações financeiras e cadastrais

## Estilo

- Corporativo
- Clean
- Minimalista
- Moderno
- Sem emojis
- Ícones lineares

## Paleta

### Base
- Azul quase preto: #0F172A
- Azul profundo: #111827
- Branco: #FFFFFF
- Fundo claro: #F8FAFC
- Cinza borda: #E2E8F0
- Cinza texto: #334155
- Cinza secundário: #64748B

### Módulos
- Hotéis: #14B8A6
- Valores a pagar: #EF4444
- Reembolso: #EAB308

### Ação
- Azul principal: #2563EB
- Sucesso: #16A34A
- Erro: #DC2626
- Aviso: #F59E0B

## Tipografia

Fonte principal: Segoe UI, Inter, Arial, sans-serif.

## Componentes

### Botões
- Primário
- Secundário
- Perigo
- Sucesso
- Botão fantasma

### Inputs
- Altura confortável
- Bordas arredondadas
- Foco azul suave

### Tabelas
- Cabeçalho discreto
- Linhas com hover
- Checkbox de seleção
- Barra de ações em massa quando houver itens selecionados

### Cards
- Fundo branco
- Borda leve
- Sombra suave
- Cantos arredondados

## Layout

### Login
- Nome TRES em destaque
- Descrição abaixo
- Card de acesso
- Visual limpo

### Dashboard
- Menu lateral recolhível
- Topbar com pesquisa e perfil
- Cards de pendências
- Indicadores por perfil
